# 实例附属数据清理方案（待实施）

本文件规定后续实现边界；当前没有自动清理 WebView2 与实例日志的功能。

- 仅移除记录：只修改注册表，保留 Home、WebView2 数据与日志，遵守现有“不删除文件”承诺。
- 删除文件并移除：现有 Home 删除成功、注册表写入成功后，才清理本次实际移除的全部实例 ID 对应的附属数据。确认窗口必须说明会删除登录状态、本地网页存储和实例日志。
- 历史孤儿：提供单独的预览和用户确认入口，不能仅因 ID 不在注册表就自动删除。保留的数据可能来自“仅移除记录”。

## 执行保护

注册表读取、解析或结构验证失败时立即中止，不把失败当作空列表。清理与启动、移除共用操作锁；检查宿主及其 DSH 子进程确实退出，注册表缺失不等于进程已退出。

只接受严格匹配 `^instance-[0-9]+-[0-9]+$` 的 ID。由统一路径函数产生目标，在 AppData 的 webview2 与 logs 固定子目录内验证绝对路径；拒绝目录链接、junction 和其他重解析点。不得递归扫描 Home 或整个 AppData。

日志仅匹配该 ID 的 `.log` 和 `.log.<数字>`，保留 desktop.log、dsh-web.log 和其他实例文件。清理不得跟随父目录链接。

附属清理失败不回滚已完成的 Home 删除，但必须向用户显示残留路径及原因。后续重试需再次检查归属和进程状态，不能只在日志中警告并声称完全成功。

## 验收

覆盖仅移除记录全部保留、共享 Home 删除覆盖全部受影响 ID、非法 ID、注册表损坏、运行中实例、目录链接、日志精确匹配、占用失败和重试。后端实现后重启应用，使用临时独立 Home 验证两种移除操作。

旧交接中的直接管道删除命令不再作为执行方案。凭据检查结论应限定为“已检查范围内未发现”，不得以少量模式扫描宣称没有任何泄露。
