# 启动器视觉与交互规范

作用范围是 Launcher、托盘与实例配置界面，不覆盖 DSH 原生 Web 业务。本文整理 [AGENTS.md](../AGENTS.md) 的视觉约束；token 实际值以 [main.css](../src/style/main.css) 为准，不在文档重复维护整套色值。

## 组件与主题

- 使用 React、Tailwind CSS 4、HeroUI 和 Gravity UI Icons；优先复用现有组件，不为已有图标另画 SVG。
- 默认主题为 `mist-blue-sakura-pink`，配置默认值、加载回退和前端初始值保持一致。
- 页面布局优先 Tailwind；共享主题、动效、第三方覆盖放 main.css。弹层、提示与菜单也必须跟随主题。

| Token | 语义 |
| --- | --- |
| --launcher-brand / --launcher-brand-strong | 主操作、强调文字 |
| --launcher-canvas | 页面底色 |
| --launcher-surface / --launcher-sidebar | 内容与侧栏表面 |
| --launcher-selected | 选中状态背景 |
| --launcher-border | 分隔和边框 |
| --launcher-ink / --launcher-muted | 正文与辅助文字 |
| --launcher-danger | 破坏性动作与错误强调 |

不要从某个主题复制固定颜色到新页面。继承 HeroUI 语义色时检查按钮文字、禁用态、焦点与 portal 中的对比度。状态不能只用颜色表达。

## 布局与信息层级

顶部一级导航固定为启动、下载、协作、设置、更多。实例配置中的左侧实例列表覆盖式展开，不挤压配置内容。下载页共享目标实例选择器，避免子页各自维护不同目标。

普通内容使用紧凑正文和辅助文字；标题用于说明当前任务，不使用营销式大标题。沿用所在页面字号层级，不任意新增字号体系。卡片通常 rounded-md，避免卡片套卡片和装饰性渐变球。

工具栏、分页、图标按钮保持稳定尺寸。动态状态文字不得推移其他控件；计数使用 tabular-nums。窄窗口中路径和长名称应换行或截断，并保留必要的完整内容访问方式。避免整页水平滚动。

## 操作与反馈

| 状态 | 必须明确的信息 |
| --- | --- |
| 加载 | 正在读取什么；不可操作区域禁用 |
| 空状态 | 为什么为空，以及可执行的下一步 |
| 运行中 | 具体实例/任务、阶段，必要时提供取消 |
| 取消中 | 等待退出，不提前宣称已经停止 |
| 失败 | 原因、保留现场、重试或诊断入口 |
| 完成 | 真实结果；需要刷新的列表及时更新 |

长操作必须持续可见。有可测量总量时展示确定进度（宽度钳制在 0–100）；未知总量使用不确定状态，不估造百分比。安装进度的实现约定：后端发 `progress: -1` 时渲染脉冲进度条、不写 `aria-valuenow`、隐藏百分比数字，只展示可读的阶段文案；`progress >= 0` 时才渲染确定宽度和数字。完成事件不代表整个实例已经健康。剩余待验证项见 [TODO](../TODO.md) 的 PROGRESS-01。

被安全守卫拒绝的破坏性操作（例如 Home 仍被上次会话遗留的 DSH 进程占用）要有自己的可见状态：说明拒绝原因和恢复步骤，而不是复用通用失败文案让用户以为可以再点一次。

陌生图标按钮必须有 aria-label 或 tooltip；错误消息使用合适的 status/alert 语义。键盘焦点应可见，禁用按钮不可只降低颜色却仍能触发操作。删除 Home 必须明确影响范围，与仅移除记录在文案上区分。

日志提供复制入口，并说明复制的是完整日志还是前端截取；清空展示与删除持久日志是不同操作。所有用户可见文本同步维护中英文扁平 key，后端输出阶段文案也需双语。

## 动效与桌面行为

页面和实例切换优先 transform/opacity，尊重 prefers-reduced-motion；进度宽度过渡和脉冲也要关闭或降级。不为轻量动画引入重型依赖。

顶部空白区域可用 data-tauri-drag-region；交互按钮保留点击行为。窄窗口测试拖拽、一级导航、最小化和关闭是否冲突。关闭启动器隐藏到托盘，不能在视觉交互中暗示实例都已退出。

## 视觉回归

每次共享布局或主题修改至少检查：默认及其他主题、窄窗口长文本、空/错误/运行/禁用状态、键盘焦点、减少动效设置、弹层主题、分页边界。不要以单张默认主题截图代替这些验证。
